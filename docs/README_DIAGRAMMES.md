# Diagrammes

Le dossier `uml/` contient les sources PlantUML modifiables :

1. cas d'utilisation ;
2. activité du pipeline ;
3. composants logiciels ;
4. séquence de consultation ;
5. déploiement local Windows ;
6. carte générale du mémoire.

Le dossier `figures/` contient les rendus visuels utilisés dans la documentation technique.

Principe retenu : les diagrammes décrivent ce que le prototype réalise effectivement. Le diagramme de classes conceptuel peut être conservé dans le mémoire uniquement s'il est présenté comme un modèle du domaine et non comme une représentation de classes Python persistées dans une base.
